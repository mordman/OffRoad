# OffRoad

## Проверка

```bash
npm run build
```

Команда проверяет синтаксис игровой точки входа и вынесенных ES-модулей без установки зависимостей.

## Структура

- `index.html` содержит HTML-оболочку и HUD-разметку.
- `src/styles/main.css` содержит стили интерфейса.
- `src/game/main.js` содержит игровой цикл и runtime-логику.
- `src/game/math.js` содержит общие математические функции, шум и генераторы случайных чисел.
- `src/game/config.js` содержит настройки мира, времени и погоды.
- `scripts/check.mjs` выполняет воспроизводимую проверку сборки.
